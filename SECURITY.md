# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| Latest  | ✅        |

## Reporting a Vulnerability

If you discover a security vulnerability in Disc Forge, please **do not**
open a public GitHub issue.

Instead, report it via one of these methods:
- **Email:** emcg0211@gmail.com
- **GitHub:** Open a [private security advisory](https://github.com/emcg0211/Disc-Forge/security/advisories/new)

We aim to respond within 7 days. Please include:
- A description of the vulnerability
- Steps to reproduce it
- Any potential impact you've identified

We will acknowledge receipt, investigate, and coordinate a fix before
any public disclosure.
